# 🌸 ScentMatch AI

## AI-Powered Perfume Recommendation Platform

ScentMatch AI is a full-stack web application designed to help users discover perfumes based on their fragrance preferences.

The platform allows users to explore perfumes, provide scent preferences, receive personalized recommendations, save favorite fragrances, and interact with an AI-powered scent assistant.

---

## 🚀 Features

### 👤 User Features

- User Registration and Login
- Secure Authentication using JWT
- Browse and Search Perfumes
- View Detailed Perfume Information
- Personalized Perfume Recommendations
- Scent Preference Quiz
- Save Favorite Perfumes
- Manage User Preferences

### 🤖 AI Features

- AI-powered scent recommendations
- Personalized fragrance suggestions
- Gemini AI integration
- AI Scent Assistant

### 👨‍💼 Admin Features

- Add New Perfumes
- Upload Perfume Images
- Manage Perfume Information
- View and Manage Perfume Collection
